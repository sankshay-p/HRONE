# HRONE

1. Project Introduction – Clario WorkPulse
Project Title: Clario WorkPulse – Employee Attendance & Analytics Dashboard
Clario WorkPulse is a web-based employee attendance management and analytics system designed to monitor employee working hours, punctuality, shift timings, and departmental performance.
The application provides an interactive dashboard that allows employees and managers to track attendance records, compare performance, and make data-driven decisions.
The system uses MongoDB 7.0 for storing attendance information and provides visual analytics through charts, performance indicators, and shift-timing comparisons.
2. Key Features
1. Employee Attendance Tracking: Monitors daily and weekly attendance records.
2. Work Hours Analytics: Calculates total working hours and daily averages.
3. Punctuality Monitoring: Tracks late arrivals and attendance compliance.
4. Department Ranking: Compares employees based on attendance performance.
5. Shift Timing Analysis: Visualizes scheduled shifts against actual punch-in and punch-out times.
6. Weekly and Monthly Reports: Provides attendance summaries for selected periods.
7. Peer Comparison: Helps managers evaluate attendance patterns across employees.
